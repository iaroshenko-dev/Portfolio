# Финансовый рынок

Количественные исследования торговых стратегий и рыночных гипотез. При публикации каждой работы указываются метод, данные, проверяемый код, результаты и ограничения.

Принципы
1. Фиксировать проверяемую гипотезу и правила до оценки результатов, когда это возможно.
2. Отделять поиск закономерностей от независимой проверки; явно указывать, если проверка не была полностью независимой.
3. Учитывать комиссии, издержки исполнения, изменения состава рынков и ограничения исходных данных.
4. Не представлять модельную доходность как реальные сделки.
5. Публиковать отрицательные выводы, не подгоняя параметры для «спасения» гипотезы.

### Donchian Four-Week Rule: главный результат

- **1985–2009:** +8,94% средней годовой арифметической доходности после модельных издержек; Sharpe 0,812.
- **2010–2026:** +0,09% в год после модельных издержек; Sharpe 0,008.
- Основная реализация использовала 20-дневный канал по закрытиям (приближение, не точное воспроизведение внутридневного пробоя максимумов/минимумов).


Историческая проверка классического трендового правила на широкой выборке фьючерсов. Современная проверенная реализация не подтвердила устойчивого преимущества после модельных издержек.
