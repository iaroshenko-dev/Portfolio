# Jupiter

**Локальная программа для голосового ввода текста в Windows.**

Jupiter преобразует речь в текст и позволяет вводить его в используемое приложение. Распознавание речи работает локально, без передачи голосовой диктовки в облако. Программа также поддерживает голосовые команды редактирования.

Это страница продукта в портфолио, а не публичный репозиторий исходного кода. Ссылку на дистрибутив и подробную документацию добавим после отдельной публикации.
